# 比赛操作手册（5 分钟流程 + 现场 SOP）

## 一、比赛时间线（总共 5 分钟，共 110 分）

| 时间 | 动作 | 得分点 |
|------|------|--------|
| **赛前（不计时）** | 打开程序、启动可视化面板和仿真环境、调整窗口 | 评分项 1（10 分） |
| T+0:00 | 向裁判申请开始，裁判给题（或出题程序随机出题） | — |
| T+0:00 | 计时开始，同时启动机器人作业 | — |
| T+0:00~0:20 | 大模型解析题目 → 输出 `[red,4,A;blue,1,C]` → 面板显示 | 评分项 2（10 分） |
| T+0:20~4:30 | 逐个货物：导航 → 识别 → 抓取 → 搬运 → 放置（5 个货物） | 评分项 3、4（各 20 分） |
| 全程 | 机器人避障（2 个动态障碍物） | 评分项 5（10 分） |
| 全程 | 面板实时反馈路径、进度、夹爪状态 | 评分项 6（10 分） |
| 全程 | 场景复杂度（已提前设计好） | 评分项 7（10 分） |

> ⏱ **时间预算建议**：每个货物 45 秒（导航 20s + 抓取 12s + 搬运 13s）。
> 如果某个货物卡住超过 60 秒，直接跳过进入下一个，**先保住后面的抓取分**。

## 四、正式比赛命令（裁判给题后）

```bash
# 方式 A：用官方出题程序（把题目文本喂给解析节点）
ros2 topic pub --once /competition/question std_msgs/msg/String \
  "{data: '题目:每个衣柜有5件衣物;...设T恤衣柜数量为x,裤子衣柜数量为y,计算x、y分别为多少。映射规则:x代表红色,y代表蓝色,数量大于等于3的去A区，其他颜色去C区'}"

# 方式 B：直接作为参数传入
ros2 run llm_comp llm_task_parser --ros-args -p question:="题目:....映射规则:..."

# 方式 C：模拟出题程序随机出题（自测）
ros2 run llm_comp question_generator
```

解析结果会立刻出现在面板上，并自动触发 `task_manager` 开始作业。

## 五、故障处理

| 现象 | 原因 | 处理 |
|------|------|------|
| 面板没有指令 | 大模型超时/欠费 | 解析节点会自动规则兜底，看 `[解析来源: rule]`；也可 `-p use_llm:=false` 强制兜底 |
| rviz 提示没有 map->odom | 未给初始位姿 | rviz 里 "2D Pose Estimate" 点一下机器人位置和朝向 |
| 机械臂不动 | 控制器未激活 | `ros2 control list_controllers`，应看到 `arm_controller`/`gripper_controller` 为 active |
| 抓不起来 | 关节角没标定 | 用 `ros2 run mybot auto_grasp_moveit.py` 或手动调，把结果写进 `competition.yaml` 的 `arm_poses` |
| 导航撞障碍物 | Nav2 参数偏保守 | 调 `bot_navigation/param/originbot_nav2.yaml` 里的 `inflation_radius`、`controller_frequency` |
| 货物不动 | 吸附服务没调用 | `ros2 service list \| grep LINK`，确认 `/ATTACHLINK`、`/DETACHLINK` 存在 |

## 六、提交材料（省赛/区域赛）

1. **视频**：电脑 + 手机双机位，一镜到底，**不允许加速/删减/拼接/特效**，
   视频中必须展示**官方比赛系统 U 盘和 U 盘编号**。
2. **技术文档**：Word，首页注明赛道名称（算法应用赛）、赛题名称（大模型技术创新赛）、
   参赛编号、团队名称、团队成员。草稿见 `04_技术文档（提交用草稿）.md`。
3. **算法源码**：压缩包（用 `06_脚本/99_打包提交材料.sh` 生成）。
4. 三项统一上传**百度网盘**。
