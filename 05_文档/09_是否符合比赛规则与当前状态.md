## 二、但有一个关键区别：**用哪台"控制器"**

规则里反复提到：

> 参赛作业设备需使用**规定控制器**……官方比赛系统 **U 盘**（视频中必须展示 U 盘和 U 盘编号）

也就是说：**正式比赛用的是组委会发的 U 盘启动的 Ubuntu 系统 / 预装好的虚拟机**，
里面已经装好了 ROS2、Gazebo、官方场景、官方出题程序。

而你这台电脑：
- 原本**没有** Gazebo、没有 Nav2、没有 rosbridge；
- `sudo` 需要密码，我无法用 `apt` 安装；
- 所以我用 conda（RoboStack）在你的用户目录下搭了一套**功能等价**的独立环境。

### 两套环境怎么分工

| | 官方 U 盘/虚拟机环境 | 我给你搭的这套（`~/llm_comp`） |
|---|---|---|
| 用途 | **正式比赛当天用** | 赛前练习、调算法、写文档、排练流程、录视频 |
| 场景 | 官方场景（不能改结构） | 我改造过的 `competition.world`（为了练场景设计分） |
| 出题程序 | 官方出题程序 | 我写的模拟出题程序 |
| 地图 | 需要你自己建 | 我已经建好 |

> ⚠ **重要**：正式比赛请用官方 U 盘环境。
> 我这套的价值在于：**让你现在就能把算法、代码、流程全部跑通、调好、录好视频**，
> 到时候把 `src/llm_comp/` 这个功能包（和你的场景文件）拷到官方环境里即可。

## 三、你截图里那两个现象，现在解释清楚了

### 1. "进不去 rviz，只有一个坐标系，机器人一动不动"

**原因（已修）**：AMCL 没收到初始位姿 → `map` 坐标系不存在 → 代价地图卡在 activating
→ Nav2 的控制器/规划器无法激活 → 机器人当然不动、rviz 里也没东西可显示。

**修复**：我新写了 `auto_initial_pose` 节点，把 Gazebo 的真值位姿自动喂给 AMCL，
相当于自动帮你点了 `2D Pose Estimate`。
实测：AMCL 定位误差 **0.05 m**，完全正确。

### 2. "第二张图里没有雷达扫描"

Gazebo 里的激光雷达在 URDF 里设了 `gz_visualize="false"`，**Gazebo 窗口本来就不显示射线**，
这是官方的设置，不是故障。激光数据是有的（`/scan` 实测 20 Hz）。

要看激光，在 **rviz** 里看：加 `LaserScan` 显示并选 `/scan`。
之前 rviz 里看不到，也是因为 `map` 坐标系不存在（同一个根因），修复后就能看到了。

## 四、还有一个坑：rosbridge 崩了

你终端里的报错：

```
ModuleNotFoundError: No module named 'cbor2'
```

`rosbridge_server` 需要 `cbor2` 这个 Python 包，conda 环境里没带上。
**已修**：`conda install cbor2`，实测 9090 端口正常监听，不再报错。

### 路径跟随怎么调（建议在 rviz 里看着调，最直观）

在 rviz 里加上这几个显示，就能看出问题在哪：

- `Global Plan` → `/plan`（规划路径）
- `Local Plan` → `/local_plan`（控制器实际要走的）
- `Costmap` → `/local_costmap/costmap`、`/global_costmap/costmap`
- `Particle Cloud` → `/particle_cloud`（AMCL 粒子，看定位是否发散）

然后按顺序试：

```yaml
# 01_dev_ws/dev_ws/src/llm_comp/config/nav2_competition.yaml
controller_server:
  ros__parameters:
    FollowPath:
      desired_linear_vel: 0.20          # 先降到 0.2 试（越小越稳）
      lookahead_dist: 0.5               # 前视距离
      min_lookahead_dist: 0.25
      max_lookahead_dist: 0.8
      rotate_to_heading_angular_vel: 0.8
      use_rotate_to_heading: true       # 原地转向，差速车必开
    general_goal_checker:
      xy_goal_tolerance: 0.35           # 放宽终点容差，避免到点前反复纠
      yaw_goal_tolerance: 0.6
local_costmap:
  local_costmap:
    ros__parameters:
      width: 6                          # 局部代价地图大一点
      height: 6
      robot_radius: 0.30                # 按实际车体调（现在是 0.22，偏小）
      inflation_radius: 0.45            # 太大容易把路堵死
```

改完重启 Nav2 即可（不用重新编译）。
