# 场景设计改造指南（对应评分项 7，10 分）

## 一、规则原文

> 障碍物、货物位置、放置区均由选手自行设计，根据增加复杂度评分。
> ① 货物在场景中不同位置，距离不小于 2m；
> ② 放置区在场景中不同位置，至少隔一面墙；
> ③ 存在至少两个有效障碍物。
> 每点 5 分，共 10 分。

官方讲解补充：**满足其中两点即符合该项 10 分要求**；两处表述有差异，
**建议赛前向组委会确认**（QQ 群 169391662）。稳妥做法是三点全满足。

同时规则明确：

> 场景中目前元素**不能删减**，目标货物位置、放置区域位置**可以自行设计**，
> **可以增加元素**。

本项目的做法严格遵守这一条：**只增加、不删除**。

## 二、官方原始场景的问题

| 检查项 | 官方 `room.world` | 是否满足 |
|--------|-------------------|----------|
| 货物间距 | 红色立方体在 y=1.0 上排成一行，x 从 -1.5 到 -1.9，**间距仅 0.1 m** | ❌ |
| 放置区 | A(3.0, 1.0)、B(3.0, 0.0)、C(3.0, -1.0) 在**同一条直线上，间距 1 m，中间无墙** | ❌ |
| 障碍物 | 无 | ❌ |

## 三、一键生成合规场景

```bash
python3 /home/robo/llm_comp/06_脚本/生成比赛场景.py
```

它做的事情：

1. 读官方 `room.world`（**所有原有元素原样保留**：`ground_plane`、`PAL_office` …）；
2. 按 2.2 m 网格重摆 10 个货物 → 最小间距 **2.20 m** ✅；
3. 给每个货物**新增**一个 0.75 m 高的支撑台（否则货物悬空会掉到地上）；
4. 在 A/B/C 三区之间**新增 2 面隔墙** → 三区两两被墙隔开 ✅；
5. **新增 2 个可移动障碍物**（非 static，圆柱体）✅；
6. 输出到 `mybot_description/worlds/competition.world`（**不覆盖** `room.world`）。

然后自动跑校验：

```
① 货物两两距离 >= 2 m   ✓ 全部满足，最小间距 2.20 m
② 放置区至少隔一面墙     ✓ A↔B / A↔C / B↔C 都被墙隔开
③ 至少 2 个有效障碍物    ✓ 共 2 个
结论: ✓ 三项要求全部满足（可拿满 10 分）
```

## 五、动态障碍物怎么调

障碍物轨迹写在 `config/competition.yaml`：

```yaml
obstacles:
  obstacle_1: "-1.6,-0.3:1.6,0.3"   # 语法: 名称:Ax,Ay:Bx,By（在两点间往复）
  obstacle_2: "0.4,1.8:0.4,-1.8"
```

`dynamic_obstacles` 节点会读取并驱动它们运动（默认 0.35 m/s，可调 `speed`）。

> ⚠ **有效性判定**：规则要求障碍物必须位于「机器人前往货物或放置区的**路线附近**」，
> 如果可移动物位置完全不影响任务，会被判为**无效障碍**、不给分。
> 所以障碍物轨迹要横穿机器人从起点到货物、从货物到放置区的必经之路。
> 建议赛前把 `obstacle_1/2` 的线段画在地图上核对一下。

## 六、地图要重新建

改造场景后，`bot_navigation/maps/map.yaml` 这张官方地图就和实际场景对不上了，
Nav2 会撞墙。需要用新场景重新建图：

```bash
source /home/robo/llm_comp/06_脚本/env.sh

# 终端 1：启动新场景
ros2 launch llm_comp competition_world.launch.py

# 终端 2：用 slam_toolbox 建图（或官方自带的 cartographer）
ros2 launch bot_navigation cartographer_gazebo.launch.py
# 用 teleop 或 rviz 的 2D Nav Goal 把机器人开一圈
ros2 run teleop_twist_keyboard teleop_twist_keyboard

# 终端 3：保存地图
ros2 run nav2_map_server map_saver_cli -f \
  $ROS_WS/src/yzbot/bot_navigation/maps/competition_map
```

然后在 `competition.yaml` 里把 `nav.map` 指向新地图，
并在 `bot_navigation/launch/nav_bringup_gazebo.launch.py` 里把 `map_yaml_file`
改成新地图文件名（或直接新建一个 `nav_bringup_competition.launch.py`，不要改官方文件）。

## 七、场景设计分的"加分印象"

除硬性三条外，评委还会看"复杂度"。可以再加：

- 在货物周围布置**窄通道 / 拐角**，让机器人必须精确规划；
- 障碍物用**不同速度、不同轨迹**（一个横穿、一个纵向）；
- 放置区做成**凹槽 / 围栏**形式，机械臂需要更精确的放置动作；
- 场景里保留并利用官方已有的家具作为天然障碍。
