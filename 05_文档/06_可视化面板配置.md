# 可视化面板配置（Foxglove / coStudio）

比赛评分项 2「指令解析」和 6「状态反馈」**都靠可视化面板给分**，所以面板必须在
赛前调通并保存好布局。

## 一、数据链路

```
ROS2 话题 ──► rosbridge_websocket (端口 9090, WebSocket) ──► Foxglove / coStudio
```

启动 rosbridge：

```bash
source /home/robo/llm_comp/06_脚本/env.sh
ros2 launch rosbridge_server rosbridge_websocket_launch.xml
```

## 二、连接方式

### Foxglove Studio（已下载，见 `08_可视化/foxglove/`）
1. 打开 Foxglove → `Open connection` → 选 **Rosbridge**；
2. 地址填 `ws://127.0.0.1:9090`；
3. 连接后左侧能看到话题列表。

### coStudio（官方推荐，需自行下载）
1. 官网 <https://www.coscene.cn/download> 下载（提供 APT 源与安装包）；
2. 使用方式与 Foxglove 完全一致（同样基于 rosbridge）；
3. 在可视化软件里把设备 IP 设为本机 IP、端口 9090。

> 官方讲解原话：「可视化软件选择 coStudio……使用方法和资料里讲的 foxglove 一样，
> 都是基于 rosbridge 实现 ROS 数据转发。」

## 三、必须显示的 4 块内容与对应话题

| 面板内容 | 话题 | 消息类型 | 建议面板类型 |
|----------|------|----------|--------------|
| **① 任务信息**（题目/抓取顺序/每种资源数量） | `/competition/task_info_text` | String | Raw Message |
| 同上（结构化，便于裁判核对） | `/competition/task_plan` | String | Raw Message |
| **② 导航路径**（规划 + 实际） | `/competition/nav_path`<br>`/competition/robot_path` | nav_msgs/Path | 3D 面板 |
| 地图 | `/map` | nav_msgs/OccupancyGrid | 3D 面板 |
| **③ 当前状态**（进度/工作状态/末端状态） | `/competition/task_status_text` | String | Raw Message |
| **汇总（一个面板看全部）** | `/competition/panel_text` | String | Raw Message |
| 货物识别结果 | `/competition/detections_text`、`/competition/markers` | String / MarkerArray | 3D 面板 |
| 机器人模型 | `/robot_description`、`/tf`、`/joint_states` | — | 3D 面板（URDF） |
| 激光雷达 | `/scan` | LaserScan | 3D 面板 |
| 相机（RGBD，装在机械臂末端） | `/camera_rgbd/image_raw`、`/camera_rgbd/depth/image_raw` | Image | Image 面板 |
| 相机（底盘前视） | `/camera/image_raw` | Image | Image 面板 |

> 💡 **省事技巧**：直接加一个 **Raw Message 面板订阅 `/competition/panel_text`**，
> 四块内容全都在里面，排版不用调、赛场上不容易出错。

## 五、网络与虚拟机注意事项（官方指导书 P…）

- 如果用 **VMware 虚拟机**：网卡要选 **桥接模式**，并在虚拟机内设置静态 IP，
  和宿主机同一网段，这样可视化软件才能连上虚拟机里的 rosbridge。
  NAT 模式下外部主机无法访问虚拟机。
- 如果用 **U 盘双系统**：直接用本机 IP 即可。
- 查看本机 IP：`hostname -I`

## 六、故障排查

| 现象 | 处理 |
|------|------|
| 连不上 9090 | 确认 rosbridge 已启动：`ss -ltnp \| grep 9090` |
| 能看到话题但没数据 | 确认对应节点在跑：`ros2 node list` |
| 中文乱码 | Foxglove 的 Raw Message 面板选 UTF-8；coStudio 同理 |
| 3D 里机器人不动 | 3D 面板需订阅 `/tf` 并把 Fixed frame 设为 `map` |
| 路径不显示 | 3D 面板里手动添加 `/competition/robot_path`，颜色设成醒目色 |
